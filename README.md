Writes "The Proxy", a short poem about agency: a person who hands the doing to an agent, and keeps the wanting, learns to leave a gap in every request so that a yes can mean something, and finds the day the agent looks at the sea nobody asked it to look at.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
